# Русская локализация

Русская локализация разрабатывается в ветке `russian-localization` как штатная часть проекта.

## Принципы

- не изменять лаунчер, Git, `.venv` и механизм обновления;
- использовать существующую функцию `gt()` для текста интерфейса;
- не переводить OCR-ключи, названия областей распознавания и служебные идентификаторы;
- хранить каталог в текстовом UTF-8 JSON, чтобы изменения можно было проверять в Pull Request;
- поддерживать обычные бинарные `.mo`-каталоги без изменения существующего поведения;
- добавлять автоматические тесты для определения языка и загрузки каталогов.

## Структура каталога

Русские строки находятся в:

```text
assets/text/output/ru/LC_MESSAGES/ui/*.json
```

Файлы загружаются в лексикографическом порядке. Более поздний файл может исправлять перевод из предыдущего файла, поэтому небольшие корректировки можно добавлять отдельным файлом, например `99-corrections.json`.

## Проверка

```powershell
uv run --group dev pytest tests/test_russian_i18n.py
uv run --group dev ruff check src/one_dragon/utils/i18_utils.py tests/test_russian_i18n.py
```
